# SeekVec 示例文档

本目录提供 4 篇示例文档，用于在应用里体验「导入 → 分块 → 端侧向量化 → 写入 seekdb → 混合检索」
的完整流程。文档内容为本项目原创，与 `data/eval` 的评测语料相互独立（评测语料请勿用于演示，
避免把评测集当作演示数据而失去评测意义）。

## 使用方式

1. 启动应用（`npm run dev`），等待模型加载完成；
2. 在「导入」面板中一次选中本目录下 4 个 `.md` 文件，点击导入；
3. 导入完成后在检索面板尝试：`seekdb 和普通数据库有什么不同`、`量化后的模型体积`、
   `浏览器里怎么跑 embedding`、`hybrid search 怎么融合` 等查询，
   可对比「向量」与「混合（keyword）」两种模式的结果差异。

## 文件说明

| 文件 | 语言 | 主题 |
|---|---|---|
| `seekdb-简介.md` | 中文 | seekdb 定位、单一引擎、部署方式 |
| `混合检索与索引.md` | 中文 | 混合检索、BM25/RRF、HNSW、索引刷新 |
| `on-device-inference.md` | 英文 | 浏览器端 Transformers.js / WebGPU / WASM 降级 |
| `quantization-and-benchmark.md` | 英文 | INT8/FP16 量化、体积压缩比、质量评测口径 |

- 均为 UTF-8 单段落 Markdown（无标题行），导入后中文文档各为 1 个 chunk，
  较长的英文文档按浏览器默认参数（256 字符）切成 2 个 chunk；
- 内容是项目自行编写的说明性文字，许可随仓库（可自由替换为真实笔记）；
- 若想演示多 chunk 文档，可把同一文件内容复制两份（中间空一行）后导入。
