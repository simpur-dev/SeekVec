## 5. 已知限制（报告已披露，不隐瞒）

- WebGPU 依赖硬件/驱动：不同机器 `fp16+WebGPU` 可能不可用，脚本会记录实际后端并标注降级；本机实测可用（NVIDIA Lovelace）。
- 评测集为项目自建（60 查询、单标注人），用于量化前后相对比较；绝对召回不代表通用 benchmark。
- fp16 在 Node CPU 上被 ORT 上采样为 fp32，Node 侧 fp16 与 fp32 一致；WebGPU 的 fp16 真实质量以浏览器结果为准。
- seekdb 镜像在 `docker-compose.yml` 与 `.env.example` 中默认固定为实测 digest（1.4.0）；升级需通过 `SEEKDB_IMAGE` 显式覆盖并重新验证。
- 冷启动的浏览器三层缓存由脚本清空 user-data-dir/CacheStorage，口径为同机同浏览器可比。
- 官方 3.2 建议表的组合覆盖：量化前基线 FP32+WASM、INT8(q8)+WASM、FP16+WebGPU（每后端起一个量化方案代表）；未另跑 INT8+WebGPU、FP16+WASM 四象限，结论按“INT8 或 FP16”口径成立。
- WebGPU 不可用路径是同一台机器通过强制 WASM / 屏蔽 `navigator.gpu` 验证的，未使用另一台无 GPU 真机；应用侧降级逻辑与 UI 提示均有记录。
