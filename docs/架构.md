# SeekVec 架构说明

## 三层职责

| 层 | 技术栈 | 职责 |
|---|---|---|
| 用户层（Browser / Web Client）| Vite + React 18 + Tailwind | UI、拖拽导入、检索交互 |
| 端侧推理层（On-Device Inference）| Transformers.js + ONNX Runtime Web | embedding 模型加载与推理（WebGPU → WASM 降级） |
| SeekDB 数据层 | Node.js + Express + seekdb-js | seekdb server 1.3.0（Windows MSI）或嵌入式（Linux/macOS）；集合管理、文档入库、混合检索 |

赛题规则 1 + 规则 6：embedding 严格在浏览器端完成，server 禁止 import 任何 ONNX / embedding 库。

## 进程拓扑

```
npm run dev  →  predev (check-seekdb.mjs)  →  concurrently
                                              ├─ server/  (Node + tsx watch, http://localhost:3001)
                                              └─ web/     (Vite, http://localhost:5173)
                                                        │  /api/* 反向代理 → 3001
```

**SeekDB 运行模式（按平台）：**

| 平台 | 模式 | 说明 |
|---|---|---|
| Windows | seekdb server 1.3.0 MSI | 本机 `127.0.0.1:2881`，`embeddingFunction: null`，server 端零推理 |
| Linux/macOS | 嵌入式（SEEKDB_PATH） | 本地数据库文件，`embeddingFunction: null` |
| Windows 嵌入式 | ❌ 不支持 | seekdb 官方明确标注 "Not supported yet"，会挂死 |

## 双集合设计

| 集合 | 维度 | Modality | 全量索引 | 用途 |
|---|---|---|---|---|
| `kb_text_en` | 384 | text | ik smart | 英文文本 |
| `kb_text_zh` | 512 | text | ik smart | 中文文本（首版默认）|
| `kb_image` | 512 | image | — | 图片（v1.1）|

- 文本集合：`VectorIndexConfig(HNSW, cosine) + FulltextIndexConfig(ik_mode)`
- 图片集合：仅 `VectorIndexConfig(HNSW, cosine)`，无 fulltext
- `embeddingFunction: null`：向量由 web 端推理后经 HTTP 写入

## 数据流

### 入库（文本）

1. `IngestPanel` 触发 `useIngestText.ingestFiles(files, collectionName)`
2. `readTextFile` → `chunkText`（256 字符 / 32 重叠）
3. `useEmbedding.embed(batch)` 端侧推理（批 16 条）
4. `ingestDocuments` → POST `/api/documents` → `collection.add(...)`
5. 返回 `count` 写入 `kbStore`

### 检索

1. `SearchPanel` 触发 `useSearch.searchAll(query, keyword, topK)`
2. 文本管线：`embed([query])` → POST `/api/search` → `collection.hybridSearch({ knn, whereDocument })`（RRF 在 SeekDB 内合并）
3. 图片管线（v1.1）：CLIP 文本塔编码 query → 查 `kb_image`
4. UI 分区呈现两条结果，**不做跨空间分数拼合**

## 关键模块

| 文件 | 职责 |
|---|---|
| `web/src/inference/models.ts` | `MODEL_REGISTRY` 模型注册表 |
| `web/src/inference/backend.ts` | 后端探测 WebGPU → WASM |
| `web/src/inference/pipeline.ts` | 多模型懒加载 + `loadModelWithFallback`（运行时失败自动降级）|
| `web/src/inference/chunk.ts` | 文本分块 |
| `web/src/inference/quantize.ts` | 量化方案元数据 |
| `web/src/db/api.ts` | HTTP API client |
| `server/src/db/schema.ts` | Schema factory（`dimension` + `modality` 参数化）|
| `server/src/db/collections.ts` | 集合生命周期管理 |
| `server/src/routes/*.ts` | 4 个 HTTP 端点（collections / documents / search / images）|
| `scripts/bench.ts` | fp32 vs int8 余弦相似度 + 召回率评测 |

## 降级策略

1. **启动探测**：`detectBackend()` 检查 `navigator.gpu`
2. **运行时失败**：`loadModelWithFallback` 在 pipeline 初始化失败时自动切到 WASM
3. **UI 提示**：`BackendBadge` 用绿色 / 琥珀色徽标实时显示当前后端，WASM 模式下展示降级原因
4. **WASM 多线程**：dev server 注入 COOP/COEP 响应头，启用 `SharedArrayBuffer`

## 版本边界

- **v1（首版提交）**：文本管线，默认 bge-small-zh，中英切换，bench 评测
- **v1.1（stretch）**：图片管线（CLIP 视觉塔 + 文本塔），双集合调度

## 版本边界说明

- seekdb server 模式与嵌入式模式均为赛题允许形态（规则 2 原文："seekdb-js 嵌入式**或本地 server**"）
- Windows 嵌入式不在范围内（seekdb 官方 docs.seekdb.ai 明确标注 "Not supported yet"）
